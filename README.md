# Looplords

Rundenbasierter Roguelite-Deckbuilder auf einem kreisförmigen Brett — React + Tailwind, rein im Browser.

## Starten

```bash
npm install
npm run dev
```

Öffne die angezeigte URL (standardmäßig http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Assets

Sprites aus dem Ordner `assets/` werden für Spieler, Gegnertypen und Bosse eingebunden. Fehlen Dateien, werden farbige Fallback-Kreise genutzt.
