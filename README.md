# Looplords

Rundenbasierter Roguelite-Deckbuilder auf einem kreisförmigen Brett — React + Tailwind, rein im Browser.

## Starten

```bash
npm install
npm run dev
```

Öffne die angezeigte URL (standardmäßig http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Assets

Alle Bilder liegen unter `assets/`:

- `assets/chip.png` — Chip-Sprite
- `assets/characters/` — Spieler- und Gegner-Sprites
- `assets/ruins/` — Brett, UI und Hintergründe (Ruins-Tileset)

Fehlen Dateien, werden farbige Fallback-Kreise genutzt.
